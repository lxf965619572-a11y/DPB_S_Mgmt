# S波段天线管理系统

## 项目简介

S波段天线管理系统是一个用于管理和控制S波段天线阵列的嵌入式软件系统。

## 目录结构

```
.
├── s_band_antenna_mgmt/      # 主要代码目录
│   ├── src/                  # 源代码
│   ├── include/              # 头文件
│   ├── config/               # 配置文件
│   ├── scripts/              # 部署和管理脚本
│   ├── tests/                # 测试代码
│   ├── docs/                 # 文档
│   └── build/                # 编译输出目录
├── .gitignore                # Git忽略文件配置
└── README.md                 # 本文件
```

## 快速开始

### 编译

```bash
cd s_band_antenna_mgmt
make
```

### 运行

```bash
./start.sh
```

### 测试

```bash
./run_tests.sh
```
