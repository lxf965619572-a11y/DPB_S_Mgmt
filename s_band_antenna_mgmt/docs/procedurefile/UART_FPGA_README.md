# UART与FPGA通信模块文档

## 概述

本模块实现了CPU与FPGA之间通过UART串口的双向通信，支持12种下发消息和133字节状态响应帧的解析。

## 硬件配置

- **串口设备**: /dev/ttyAMA1
- **波特率**: 921600
- **数据位**: 8位
- **校验位**: 无校验
- **停止位**: 1位
- **字节序**: 大端（Big-Endian）

## 帧格式

### 通用帧结构
```
+--------+--------+--------+--------+--------+--------+
| 帧头   | 消息ID | 长度   | 数据   | ...    | 帧尾   |
| 0xEB90 | 1 Byte | 1 Byte | N Bytes| ...    | 0x5555 |
| (大端) |        |        |        |        | (大端) |
+--------+--------+--------+--------+--------+--------+
  2字节    1字节    1字节    N字节            2字节
```

- **帧头**: 0xEB90 (大端，2字节)
- **消息ID**: 1字节，标识消息类型
- **长度**: 1字节，表示从消息ID到数据结束的长度（包含消息ID和长度字段本身）
  - 长度 = 1(消息ID) + 1(长度字段) + N(数据长度)
  - 最小值：2（无数据时）
  - 最大值：255
- **数据**: 变长（0-253字节），根据消息类型不同
- **帧尾**: 0x5555 (大端，2字节)

### 长度字段说明

长度字段的值包含了：
- 消息ID字段本身（1字节）
- 长度字段本身（1字节）
- 实际数据部分（N字节）

例如：
- 无数据的消息：长度 = 2
- 有4字节数据的消息：长度 = 2 + 4 = 6

### 完整帧长度计算

完整帧长度 = 帧头(2) + 长度字段的值 + 帧尾(2)

## 支持的消息类型

### CPU -> FPGA 下发消息

| 消息ID | 消息名称 | 触发条件 | 数据格式 |
|--------|----------|----------|----------|
| 0x01 | 相控阵工作模式 | 配置工作模式 | uint32_t (0=业务, 1=频道, 2=待机, 3=自校准) |
| 0x02 | CPRI工作模式 | 配置组网模式 | uint32_t (1=普通, 2=级联, 3=主备, 4=反向分担) |
| 0x03 | 指令波束数 | 收到小区/波束配置 | uint8_t (波束数量 n1) |
| 0x04 | 业务波束数 | 收到小区/波束配置 | uint8_t (波束数量 n2) |
| 0x05 | 相控阵复位 | 收到复位指令 | uint32_t (0=执行复位, 1=挂起复位) |
| 0x06 | 校准指示 | 收到校准请求 | uint32_t (校准参数值) |
| 0x07 | 环回控制 | 调试/测试模式 | uint8_t (0=关闭, 1=调口, 2=波束, 3=基他) |
| 0x08 | 频率与带宽 | 收到小区频点配置 | 结构体(12B): 下行频率(4B), 带宽(4B, MHz), 上行频率(4B) |
| 0x09 | 波束次数 | 调试配置 | uint16_t (次数值) |
| 0x0A | 系统时间 | 系统启动/时间同步 | 结构体(6B): 年(1B), 月(1B), 日(1B), 时(1B), 分(1B), 秒(1B) |
| 0x0B | 发射控制 | 收到TX开/关指令 | uint8_t (0=关, 1=开) |
| 0xFF | 状态检询 | 周期性任务(1秒/次) | uint8_t (Dummy字节, 无实际意义) |

## 频率编解码算法

FPGA使用特殊的频率压缩算法：

### 编码（发送频率到FPGA）
```c
uint32_t fpga_encode_frequency(uint32_t freq_khz)
{
    uint32_t quotient = freq_khz / 50000;
    uint32_t remainder = (freq_khz % 50000) * 2;
    return (quotient << 16) | (remainder & 0xFFFF);
}
```

### 解码（从FPGA接收频率）
```c
uint32_t fpga_decode_frequency(uint32_t encoded_freq)
{
    uint32_t quotient = (encoded_freq >> 16) & 0xFFFF;
    uint32_t remainder = encoded_freq & 0xFFFF;
    return quotient * 50000 + remainder / 2;
}
```

## API使用示例

### 1. 发送CPRI工作模式
```c
#include "fpga_handler.h"

// 设置为普通模式
fpga_send_cpri_mode(1);
```

### 2. 发送频率与带宽配置
```c
// 下行频率: 2100000 kHz (2.1 GHz)
// 上行频率: 1900000 kHz (1.9 GHz)
// 带宽: 20 MHz
fpga_send_freq_band(2100000, 1900000, 20);
```

### 3. 发送波束数配置
```c
// 指令波束数: 4
// 业务波束数: 8
fpga_send_beam_num(4, 8);
```

### 4. 发送系统时间
```c
// 自动获取当前系统时间并发送
fpga_send_system_time();
```

### 5. 发送发射控制
```c
// 打开发射
fpga_send_tx_control(1);

// 关闭发射
fpga_send_tx_control(0);
```

### 6. 获取FPGA状态
```c
#include "fpga_handler.h"

fpga_status_frame_t status;
if (fpga_handler_get_status(&status) == SUCCESS) {
    // 解码本振频率
    uint32_t lo_freq_khz = fpga_decode_frequency(status.lo_frequency);

    printf("本振频率: %u kHz\n", lo_freq_khz);
    printf("本振锁定: %s\n", status.lo_lock_status == 0 ? "是" : "否");
    printf("时钟同步: %s\n", status.clock_sync_status == 0 ? "是" : "否");
    printf("温度1: %u℃\n", status.temp1);
    printf("温度2: %u℃\n", status.temp2);
    printf("温度3: %u℃\n", status.temp3);
}
```

## 状态轮询机制

UART客户端内部实现了自动轮询线程，每秒向FPGA发送一次状态查询（0xFF消息），无需手动触发。

## FPGA状态到CPRI消息转换

当FPGA状态更新时，系统会自动：

1. **检查告警条件**：
   - 温度超限
   - 本振失锁
   - 时钟失步

2. **生成CPRI告警消息**：
   如果检测到告警，自动生成CPRI告警上报消息并发送给BBU

3. **响应BBU查询**：
   当BBU发送状态查询或参数查询时，从FPGA状态中提取相应信息并回复

## 注意事项

1. **字节序**：FPGA通信使用大端序，与CPRI协议的小端序不同，注意转换
2. **频率单位**：FPGA使用压缩格式，需要使用专用编解码函数
3. **状态有效性**：首次状态查询响应前，`fpga_handler_get_status()` 会返回错误
4. **线程安全**：FPGA状态管理器使用互斥锁保护，可以在多线程环境中安全使用
5. **UART权限**：确保程序有权限访问串口设备，可能需要将用户添加到 `dialout` 组

## 故障排查

| 问题 | 可能原因 | 解决方案 |
|------|----------|----------|
| 无法打开UART设备 | 权限不足 | `sudo chmod 666 /dev/ttyAMA1` |
| 收不到FPGA响应 | 波特率不匹配 | 检查FPGA端波特率配置 |
| 帧解析失败 | 帧头/帧尾错误 | 检查字节序和帧格式 |
| 频率值异常 | 编解码错误 | 使用专用频率编解码函数 |
| 状态一直无效 | FPGA未响应 | 检查UART连接和FPGA运行状态 |
